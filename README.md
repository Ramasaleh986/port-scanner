# 🔍 فاحص المنافذ (Port Scanner)

أداة بسيطة بلغة Python تفحص المنافذ المفتوحة في جهاز أو شبكة، وتنبّه على الخدمات الخطرة مع التوصية المناسبة.

> ⚠️ **تنبيه:** استخدم الأداة فقط على أجهزتك أو بتصريح كتابي. الفحص بدون إذن مخالف للأنظمة.

## الهدف من المشروع

- فهم كيف يعمل اتصال TCP.
- تعلّم كيف يكتشف المهاجم الخدمات المكشوفة، وكيف نقفلها نحن كمدافعين.
- ربط نتائج الفحص بتوصيات أمنية عملية.

## المميزات

- فحص نطاق منافذ محدد بسرعة (Multi-threading).
- تعرّف على أشهر الخدمات (SSH, HTTP, RDP...).
- ملاحظات أمنية تلقائية على المنافذ الخطرة (Telnet, FTP, SMB, RDP).
- تحقق من المدخلات (نطاق المنافذ من 1 إلى 65535).

## المتطلبات

Python 3 فقط، ولا تحتاج تثبيت أي مكتبات خارجية.

## التشغيل

```bash
python3 scanner.py 127.0.0.1 -s 1 -e 1024
```

| الخيار | الوصف |
|--------|-------|
| `-s` | بداية النطاق (افتراضي 1) |
| `-e` | نهاية النطاق (افتراضي 1024) |
| `-t` | مهلة الاتصال بالثواني (افتراضي 0.5) |

## مثال على المخرجات

```text
PORT    SERVICE     NOTE
22      SSH
80      HTTP
3389    RDP         RDP exposed to the internet is high risk. Use VPN + MFA.

Total open ports: 3
```

## ماذا تعلمت

- الفرق بين المنفذ المفتوح والمغلق والمفلتر.
- لماذا يجب إغلاق الخدمات غير الضرورية (مبدأ تقليل سطح الهجوم).
- ربط ذلك بضوابط الهيئة الوطنية للأمن السيبراني (NCA).

## تطويرات مستقبلية

- تصدير النتائج إلى ملف PDF/CSV.
- التعرف على إصدار الخدمة (Banner Grabbing).
- واجهة رسومية بسيطة.
